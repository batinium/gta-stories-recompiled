GTA Stories Recompiled 0.3.2

Fixes
- LCS: every weapon shot at the same spot in free aim (#6). Fixed in the app; your game library keeps working. Android and PC.
- Black picture on the phone's own graphics driver (seen on an Adreno 840): the driver refused the game's draw steps. Fixed there; other Adreno phones may have had the same problem. Not tested on other phones.
- Black bar at the bottom with 3-button navigation (#1): the game now draws edge to edge. Only gesture navigation was tested here; please report if the bar is still there.
- Mali GPUs failed to start (no dual-source blending): there is now a fallback. Untested, no Mali phone here.

New
- Custom GPU driver (#5), Adreno only: Settings > Custom GPU driver, pick a Turnip driver zip. No driver is included. It does not help a stock driver below Vulkan 1.3.
- Saves > Back up all saves and Restore a backup. Saves live only inside the app: uninstalling it or clearing its data deletes them, so back up before updating.
- Settings shows the size of each data folder and the free space (#3). The game library cannot move to external storage.
- Touch controls, first versions, little tested: AIM button, gestures (each can be turned off), a car-door hint on Triangle, dragging the screen turns the camera by default, L3/R3 hidden by default (Controls).
- Compatibility mode (Settings), and plainer messages with a Save report button when the game fails to start, freezes or draws a black picture.
- Prepare for Android in the PC launcher: one progress bar.
- Problem reports hold more detail (phone, GPU, driver). They never contain your disc, saves or files.

Not fixed
- VCS graphics lost on an AYANEO Pocket FIT (Adreno 750) and a graphics-driver crash on a Xiaomi (Adreno 740): cause unknown. Reports from 0.3.2 will help.
- Stock drivers that only have Vulkan 1.1 (#5), widescreen pause screen and IV/V controller layout (#2).

Updating keeps settings, saves and the game library.

Bring your own discs: nothing from the games is included. Unofficial fan project, not affiliated with Rockstar or Take-Two.
