# Security policy

If you find a security problem (for example in the launcher's updater, the downloads it makes, or the mod loader's
file handling), please **report it privately** with GitHub's private vulnerability reporting: the **Security** tab >
**Report a vulnerability** on this repository. Please do not open a public issue for it.

Say what you found, how to reproduce it and which version. You will get an answer as soon as possible; this is a
volunteer project, so please allow some days. Only the latest release is supported.
