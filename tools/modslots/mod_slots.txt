# The mod manager's slot tables and name matching, for both games (docs/ANDROID.md "Mods", docs/LCS.md "Mods").
# ONE file, read by tools/mods.py (the desktop launcher's Mods sheet) and by the Android launcher (ModFormats.java;
# packed into the APK's assets by android/app/build.gradle). Plain text so both read it without a JSON library.
#
#   <game> vehicle <model id> | <model name> | <label> | <class> | <names> | <similar>
#   <game> weapon <type> <model id> | <model name> | <label> | <class> | <names> | <similar>
#
# Names are compared lower-case with everything but a-z / 0-9 dropped (pistol_silenced = pistolsilenced). A mod's line
# or model name is looked up in this order, and the manager says which rule matched:
#   "matched by name"   the slot's own model name (column 2)
#   "alias"             <names>: the same vehicle / weapon under another name (GTA III / VC / SA / the game's own key)
#   "nearest equivalent" <similar>: a vehicle / weapon the game doesn't have, put into the closest one of the same
#                       class (an SA sports car into a sports car); the player is told and can pick another
#   "picked by you"     the player chose the slot (the manager's slot picker)
# A name may appear once per game and kind. Weapon types and model ids: VCS from the trainer (vcs_trainer.cpp);
# LCS read from the game in a run (weapon info *0x3D9B48 + 4, 0x70 per type, +0x60 the model; model infos *0x3D8720,
# +0x10 type 6 = vehicle, +0x2E the game's text key - the key is listed under <names>; labels from the game's text).
# LCS leaves out what the trainer leaves out (train, ferry, the script-only helicopters and airliner, RC toys).
